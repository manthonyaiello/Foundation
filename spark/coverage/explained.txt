# scripts/check-coverage.sh matches each violation of gnatcov's report
# against these entries and lists the ones that match none as UNEXPLAINED.
# An entry names the source file and the text of the violation's line
# (trimmed), so it survives edits elsewhere in the file:
#
#   file | line text | why it is not executed by the FFI properties
#
# A gap in the targeted tests is closed with a property, never listed here.
#
# Contract-only functions. Each is an ordinary (not ghost) expression
# function, so the compiler emits code for it, but its only callers are
# contracts (Pre, Post) and loop invariants. The FFI library builds the
# executables as a client would, without -gnata, so those contracts are not
# executed, and no executable statement calls these functions: they are
# unreachable in the code that ships, by construction. gnatprove proves
# every precondition they appear in at each call site, which is the
# assurance they carry.
