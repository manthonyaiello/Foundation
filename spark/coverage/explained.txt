# explained.txt -- the coverage violations that are explained, not gaps (#49).
#
# scripts/check-coverage.sh matches each violation of gnatcov's report
# against these entries and lists the ones that match none as UNEXPLAINED.
# An entry names the source file and the text of the violation's line
# (trimmed), so it survives edits elsewhere in the file:
#
#   file | line text | why it is not executed by the FFI properties
#
# A gap in the targeted tests is closed with a property, never listed here.
#
# A function called only from contracts (Pre, Post) and loop invariants is
# Ghost, not an entry here: the FFI library builds the executables as a
# client would, without -gnata, so the compiler emits no code for it and
# gnatcov counts no obligation in it.
#
# No entries: every statement, decision and MC/DC obligation of the units
# in coverage/units.txt is covered by the FFI properties.
