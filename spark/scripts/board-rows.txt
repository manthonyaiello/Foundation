# board-rows.txt -- the rows of the campaign's board, read by scripts/board.py.
#
# One line per function the campaign promises, which makes this file the
# board's denominator:
#
#     function | spec entity | impl entity
#
# function     The Cryptol declaration, qualified by its module as the .cry
#              file names it (AES::GF28::xTimes, SHA2::Main::step). The FFI
#              log (README "The board") names its properties' functions the
#              same way, which is how a row finds its FFI results.
# spec entity  The spec-layer Ada entity that mirrors it, fully qualified, as
#              gnatprove names it in its .spark files
#              (Foundation_Spark.AES.Spec.GF28.xTimes). For a generic, name the
#              entity of the instance that is proved
#              (Foundation_Spark.SHA2.SHA256.Step), not the generic's.
# impl entity  The implementation entity proved equal to the spec, likewise;
#              `-` until it exists.
#
# The spec and the implementation of one function live in different units, so
# a row names both. A tick that adds a spec-layer function adds its row here in
# the same PR; the tick that adds the implementation fills in the third field.
# A name that matches no .spark entity shows as "no" on the board (not built
# yet, or misspelled: the board says which entity it looked for).

# AES (#11) fills the impl column of every AES row below but Main's: the
# entities of Foundation_Spark.AES.Impl, each with a postcondition of equality
# with the row's spec entity. Main.cry's Encrypt and Decrypt are over bits,
# and the implementation over bytes stops at Cipher and InvCipher.

# SHA-2 (#16): the byte-level refinement of hash at SHA-256. Hash_Bytes is not
# a Cryptol declaration: it is SHA256::hash over a message of whole bytes,
# proved equal to SHA256.Hash on their bits (Lemma_Hash_Bytes). Its FFI check
# is against SHA256::hash through a byte-packing wrapper; M2.4 (#17) fills in
# the implementation.
SHA2::Main::hash (SHA-256, bytes) | Foundation_Spark.SHA2.SHA256_Bytes.Hash_Bytes | Foundation_Spark.SHA2.SHA256_Stream.Hash

# SHA-2 (#17): the implementation, SHA256_Stream, fills the impl column of the
# step and hash rows above. Compress is proved equal to Step. Hash, the
# one-shot hash (Init, one Update, Final), is proved equal to Hash_Bytes and to
# SHA256.Hash on the bits. The streaming interface is proved through
# Lemma_Update and Lemma_Final, and Hash_Chunked states it for every chunking
# of an array; it adds no row, since it is the same function as hash (bytes).

# HMAC (#19): HMAC/Main.cry's HMAC and HMAC_init (private in the Cryptol),
# through the SHA-256 instance of the generic Main, as packaging/Hash.cry
# instantiates them for SHA256.cry. M3.2 (#20) fills in the implementation:
# SHA256_Impl.HMAC_SHA256 (bytes, λ = 256, over two SHA256_Stream contexts)
# and SHA256_Impl.Init_Key (K0), each proved equal to the spec on the bits.
# The incremental Init/Update/Final is the same function and adds no row.
