# mutants.txt -- the mutants of the executable SPARK (#104), read by
# scripts/mutation.py.
#
# Each mutant is one small change to one line of one source, in the
# executable code (never a contract, an assertion or ghost code): an
# operator, a constant, an off-by-one bound, a loop bound, an index, a
# dropped statement or a swapped call. The script copies the checkout to a
# scratch tree, applies one mutant at a time there, and never writes a
# mutant into this checkout.
#
# Mutant lines:
#
#     id | file | line | from | to | ffi | prove | what
#
# id     A (AES.Impl), M (AES.Impl.Main), S (SHA2.SHA256_Stream),
#        H (HMAC.SHA256_Impl), F (SHA2.Functions), and a number.
# file   The source, relative to spark/.
# line   The line the change is on, in the source at the commit that adds
#        this list; `mutation.py check` fails if from is not on it, once.
# from   The text replaced, which must occur exactly once on that line.
# to     Its replacement (`null;` for a dropped statement).
# ffi    The FFI properties run for the mutant: group names (below) and
#        property names, space-separated. A survivor of these is then run
#        against every property (`mutation.py ffi --full`).
# prove  The units gnatprove proves for the mutant (-u, by file name), or a
#        group. The mutated unit, and for SHA2.Functions, which the spec and
#        the implementation share, every SHA-2 and HMAC unit.
# what   What the change is, in words.
#
# Group lines:  group NAME = MEMBER ...   (a member may be another group,
# by its name).
